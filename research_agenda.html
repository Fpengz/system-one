1. Executive Synthesis & Theoretical Framing

1.1 Formalizing System‑1 as Bounded-Computation Inference

The most productive way to think about "System‑1" in machine learning is not as a particular commercial product, neural network topology, or single forward pass. Rather, we define the research object as a family of amortized bounded-computation decision procedures:

fθ:(S,Q,C)↦qθ(Y∣S,Q,C)f_\theta : (S, Q, C) \mapsto q_\theta(Y \mid S, Q, C)fθ​:(S,Q,C)↦qθ​(Y∣S,Q,C)

where:

Contextual State S
Rich environmental state (text tokens, visual embeddings, relational schemas, knowledge graphs).
Typed Query Q
Structured task specification, rubric schema, or target question definition.
Candidate Set C
Candidate action set, allowable class choices, or discrete combinatorial constraint space.
Joint Distribution q_θ
Direct predictive distribution over decision vector Y preserving essential output dependencies.
🛡️
The Strict Computational Contract
The underlying inference graph obeys a hard bounded-compute guarantee: no open-ended search, no token-by-token deliberation with unbounded stopping time, and no input-dependent exploration graph whose depth can expand arbitrarily without a predetermined cap.

1.2 The Inference Hierarchy

This definition induces a natural and rigorous computational hierarchy:

Independent S1  ⊂  Structured S1  ⊂  Bounded-Iterative S1-K  ⊂  Adaptive S1.x  ⊂  System 2\boxed{ \text{Independent } S_1 \;\subset\; \text{Structured } S_1 \;\subset\; \text{Bounded-Iterative } S_1\text{-}K \;\subset\; \text{Adaptive } S_1.x \;\subset\; \text{System } 2 }Independent S1​⊂Structured S1​⊂Bounded-Iterative S1​-K⊂Adaptive S1​.x⊂System 2​

We operationalize the boundaries across this spectrum:

REGIME 1 • O(1) PASS
Independent S₁
Factorized marginal predictions ∏ q(yᵢ|S,Q,C) emitted in a single feedforward pass. No joint covariance.
REGIME 2 • O(1) JOINT
Structured S₁
Single-pass joint models via low-rank latent conditioning π(z|x) or copula heads. Zero autoregressive delay.
REGIME 3 • O(K) PARALLEL
Bounded S₁-K
Predetermined K rounds of parallel latent refinement (K ∈ {1,2,4,8}). Compute contract is strictly fixed.
REGIME 4 • ADAPTIVE HALT
Adaptive S₁.x
Bounded iterative inference with early stopping (K ≤ K_max). Strictly halts without expanding branch search.
REGIME 5 • DELIBERATION
System 2
Unbounded test-time compute: serial CoT reasoning, tree exploration, multi-sample verification, tool calls.

1.3 Undermining the "Fast = 1 Pass, Slow = Recurrent" Dichotomy

Traditional Misconception

OBVIATED

Equates Fast Intelligence to a single unrolled feedforward pass, and Slow Intelligence to recurrence, token generation, or iterative loops. Treats any repeated computation as System 2.

Modern Bounded Reality

2024–2026 CONSENSUS

Recurrent-depth Transformers, iterative EBMs, and masked diffusion prove that iterative refinement can be fully parallel and bounded (S₁-K). Sequential CoT is required strictly when computational graphs have irreducible serial depth.

1.4 The Central Research Target: A Computational Phase Diagram

The core research question of modern machine learning is no longer whether test-time inference compute improves performance. Rather, it is:

What intrinsic structural properties of a problem dictate whether computation should be compiled into weights, amortized into a small fixed number KKK of parallel refinement steps, or delegated to open-ended sequential deliberation?

Rather than pitting S1S_1S1​ accuracy against S2S_2S2​ accuracy on arbitrary benchmarks, our goal is to construct and empirically map the computational phase diagram governed by policy R(x)\mathcal{R}(x)R(x):

R(x)=arg max⁡r∈{one-shot,  parallel-K,  deliberate/search}[E[U(r,x)]−λ compute(r,x)−μ latency(r,x)]\mathcal{R}(x) = \operatorname*{arg\,max}_{r \in \{\text{one-shot},\;\text{parallel-}K,\;\text{deliberate/search}\}} \left[ \mathbb{E}[U(r, x)] - \lambda\,\mathrm{compute}(r, x) - \mu\,\mathrm{latency}(r, x) \right]R(x)=r∈{one-shot,parallel-K,deliberate/search}argmax​[E[U(r,x)]−λcompute(r,x)−μlatency(r,x)]

To map R(x)\mathcal{R}(x)R(x), we decouple computational problems across five structural primitives:

PRIMITIVE 1

Joint Structure

Output dependency treewidth & covariance density across simultaneous decisions.

PRIMITIVE 2

Parallel Refinement

Constant number of parallel passes (K) needed to resolve global constraints.

PRIMITIVE 3

Serial Requirement

Irreducible sequential depth that strictly forces token-by-token deliberation.

PRIMITIVE 4

Program Calibration

Higher-order joint uncertainty moments required for downstream logic composition.

PRIMITIVE 5

Value of Compute

Counterfactual marginal benefit Δ(x) of invoking S₂ deliberation over S₁ output.

2.2 Two Crucial Theoretical Realizations

💡
Observation 1: Marginal Calibration Does Not Guarantee Program Calibration

Consider two binary decision variables AAA and BBB, emitted by an independently calibrated classifier:

P(A=1)=0.9,P(B=1)=0.8P(A=1) = 0.9, \qquad P(B=1) = 0.8P(A=1)=0.9,P(B=1)=0.8

A downstream programmatic agent requires the joint satisfaction of both conditions: g(A,B)=A∧Bg(A, B) = A \land Bg(A,B)=A∧B. Under marginal calibration alone, Fréchet inequalities dictate:

P(A∧B)∈[max⁡(0,0.9+0.8−1),min⁡(0.9,0.8)]=[0.70,0.80]P(A \land B) \in \left[\max(0, 0.9 + 0.8 - 1), \min(0.9, 0.8)\right] = [0.70, 0.80]P(A∧B)∈[max(0,0.9+0.8−1),min(0.9,0.8)]=[0.70,0.80]

If the software pipeline assumes independence, it assigns p^=0.9×0.8=0.72\hat{p} = 0.9 \times 0.8 = 0.72p^​=0.9×0.8=0.72. If the real system has positive correlation (P(A∧B)=0.80P(A \land B) = 0.80P(A∧B)=0.80), the downstream expected risk is severely misestimated.

This error is not an estimation artifact or miscalibration bug in the individual heads—it is an information-theoretic failure of the interface. The marginals do not contain the joint distribution [9].

⚡
Observation 2: Fixed-Round Iterative Computation (S₁-K) is a Distinct Computational Regime

Empirical work on recurrent-depth Transformers, masked diffusion, and energy minimization demonstrates that significant reasoning occurs without sequential CoT tokens [6, 8, 18]. The central scientific problem is to rigorously identify the structural boundary where:

AK=1<AK=2<AK=4≈AS2A_{K=1} < A_{K=2} < A_{K=4} \approx A_{S_2}AK=1​<AK=2​<AK=4​≈AS2​​

versus where every fixed KKK collapses as problem depth scales to infinity.

Candidate A — Joint Latent-Variable System‑1

Modeling & Architecture
RESEARCH QUESTION
Can a fixed-cost S1S_1S1​ model capture complex dependencies across dozens of simultaneous decisions while retaining parallel, non-autoregressive inference?
CORE HYPOTHESIS
Much of the gain commonly attributed to sequential CoT on multi-decision tasks stems from conditioning on a joint latent state. It can be captured via a small latent mixture:
q(Y∣x)=∑z=1Mπz(x)∏i=1nqi(yi∣x,z)q(Y \mid x) = \sum_{z=1}^{M} \pi_z(x) \prod_{i=1}^n q_i(y_i \mid x, z)q(Y∣x)=z=1∑M​πz​(x)i=1∏n​qi​(yi​∣x,z)
WHY EXISTING METHODS FAIL
Independent heads discard covariance; autoregressive decoders impose arbitrary order and linear latency O(n)O(n)O(n); full EBMs suffer from intractable partition functions [3].
PROPOSED METHOD
Compare independent heads against MMM-component mixtures, low-rank Gaussian copula heads, and fixed-step refinement, optimizing joint NLL.
CLEAN EXPERIMENT
Synthetic multivariate Bernoulli benchmarks with tunable factor graphs; multilabel image/text tagging; constraint-dense scheduling state evaluations.
BASELINES
Independent classification heads; Autoregressive Transformer; Energy-Based Models (IRED); Masked Diffusion; Sequential LLM.
MEASUREMENTS
Joint NLL, exact-match accuracy, pairwise covariance error, compound event Brier score, inference latency (ms).
EXPECTED EMPIRICAL FINDING
A low-rank latent bottleneck (M≤16M \le 16M≤16) closes >80%>80\%>80% of the independent-to-AR performance gap on low-treewidth problems, failing only on dense high-order cliques.
FATAL FLAW
If shared representations in standard Transformers already capture sufficient decision dependence via independent linear readouts.
NOVELTY RISK
High unless framed around the bounded-compute dependence frontier rather than generic structured prediction.
FUNDAMENTAL SIGNIFICANCE
Establishes the representational limits of non-autoregressive joint probability distributions.
CANDIDATE B

Candidate B — Feasible-by-Construction System‑1

Modeling & Architecture
RESEARCH QUESTION
Can a bounded neural architecture guarantee global constraint satisfaction without combinatorial search or independent projection heuristics?
CORE HYPOTHESIS
One to four learned parallel projection steps can map unconstrained logits into a globally feasible manifold much faster than combinatorial decoders.
WHY EXISTING METHODS FAIL
Independent classification outputs violate mutual exclusivity; standard constrained decoders (ILP/Z3) become slow S2S_2S2​ bottlenecks [8].
PROPOSED METHOD
Compile linear and Boolean constraints into a differentiable projection layer unrolled for exactly KKK parallel gradient steps without dynamic convergence loops.
CLEAN EXPERIMENT
Bipartite matching, graph coloring, Sudoku fragments, and 3-SAT instances where local heuristics are adversarially deceptive.
BASELINES
Independent logits; Independent logits + ILP projection; Autoregressive decoder; IRED energy optimization; Exact combinatorial solver.
MEASUREMENTS
Feasibility rate, Hamming accuracy, exact match, runtime compute normalized against ILP solvers.
EXPECTED EMPIRICAL FINDING
Fixed refinement outperforms unconstrained models on structured tasks, but fails when constraint graphs require global backtracking.
FATAL FLAW
If simple post-hoc projection algorithms (e.g., Hungarian algorithm, greedy repair) are strictly faster and more accurate than learned neural modules.
NOVELTY RISK
High due to proximity to IRED [8]; must emphasize fixed-compute amortization vs. exact-solver phase transitions.
FUNDAMENTAL SIGNIFICANCE
Clarifies whether constraint satisfaction requires iterative search or can be compiled into feedforward geometry.
